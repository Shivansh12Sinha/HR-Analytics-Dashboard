# HR Analytics Dashboard

## Project Overview
This project analyzes HR data using Tableau to uncover insights related to employee attrition, workforce demographics, salary distribution, overtime impact, and job satisfaction.

## Tools Used
- Excel
- Tableau Public

## Key Features
- KPI Cards for Employees, Attrition, and Average Salary
- Attrition by Department Analysis
- Gender Distribution Visualization
- Salary Analysis
- Job Satisfaction Analysis
- Overtime vs Attrition Insights
- Interactive Dashboard Filters

## Business Insights
- Certain departments showed higher attrition.
- Overtime employees were more likely to leave.
- Salary patterns varied across departments.
- Workforce demographics highlighted diversity trends.
